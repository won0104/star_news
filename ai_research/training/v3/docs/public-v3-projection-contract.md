# v3 PUBLIC 선택·투영 계약 (projection r6 edge confidence / canonical r06)

`V3ConstructionResult`는 요청 범위 scalar semantic 결과다. `RawArticle` 원문은 canonical text 및 evidence 검증의 마지막 소비 시점까지 호출자가 유지한다. `project_public`은 이 결과를 읽어 **선택된 proposition부터** 노드와 간선을 만든다. 모델의 Event/Statement `primary_score`, status, producer version은 relation logit 및 구조 관계와 별개 필드다. 구성 결과에는 tensor나 DB identity가 없다.

이전 projection r4에서 Entity 노드의 `merged_mentions` 속성을 추가했고, r5는 최종 Event의 role endpoint를 역할별 하나로 제한했다. 현재 `v3-public-projection-r6-edge-confidence`는 이를 유지하며 모든 PUBLIC edge 최상위에 `confidence`를 두고 ABOUT/CAUSES의 raw `relation_logit` 속성을 제거한다. Event/Statement 표시 규칙은 `v3-span-first-minimal-edit-r06-v4`를 유지한다. Event는 원문 member span을 본체로 삼고 explicit source-detail marker가 있는 동일 episode member만 deterministic display anchor로 우선할 수 있다. 대명사 치환은 해당 원문 occurrence의 resolved role→Entity endpoint와 같은 Entity의 exact source alias가 모두 있을 때만 허용한다. 연속 치환은 모든 occurrence와 endpoint를 치환 전 source 좌표에서 확정한 다음 source 위치의 역순으로 적용하고 기존 display edit 좌표를 rebase한다. 따라서 앞선 길이 변경이나 반복 표면형이 다른 occurrence의 근거를 빌리지 않는다. Statement는 type과 Assertor를 별도 필드/관계로 유지하므로 완결 명제에 reporting clause를 재부착하지 않는다. provenance에는 article version, 사용 grounding ID, exact source grounding, edit 규칙과 source/display 범위, audit, fact invariant가 있다. 표시문은 열거된 ending 정리나 grounded 대명사 치환 때문에 원문의 연속 substring이 아닐 수 있으나 각 source grounding과 node/edge evidence는 계속 exact offset/text 검증을 통과해야 한다.

Time node와 `OCCURRED_ON`은 선택된 final Event의 실제 attachment, 유효한 `YYYY`/`YYYY-MM`/`YYYY-MM-DD`, `r06-time-public-projection-v1`이 승인한 raw semantics를 모두 요구한다. 명확한 calendar literal과 명확한 시작 anchor `~부터`는 투영하지만 `~이전`, `~이후`, 근사·기간·비교·미승인 boundary는 non-null anchor가 있어도 제외한다. node와 edge는 같은 raw occurrence evidence를 공유하며, validator가 value 형식·raw safety·evidence 동일성을 독립적으로 재검사한다. `calendar_eligible`은 여전히 value 형식 지원여부일 뿐 raw projection safety와 동의어가 아니다.

- 입력 Event/Entity closure는 `PREDICTED`이고 Event closure의 article version·content SHA가 원문과 같아야 한다. 모든 source span·role·Time·Assertor·ordered relation endpoint를 투영 전에 검증한다. final local ID만 사용한다.
- 순수 `project_public`의 기본 선택은 전체 EventCluster·Statement이다. 외부가 두 kind의 선택 ID 집합을 주거나 **외부가 정한** 유한 threshold를 넘길 수 있다. threshold와 명시 선택은 동시 사용하지 않는다. 누락 점수의 0 대체는 없고, 명시한 `diagnostic_unfiltered`일 때만 진단 출력한다. threshold는 모든 후보에 학습된 점수가 있어야 쓴다.
- 정상 serving 경로는 checkpoint-bound Primary threshold를 통과한 EventCluster 상위 3개와 Statement 상위 3개를 먼저 고른다. 추가 최대 2자리 중 첫 자리는 이미 선택된 Event와 승인된 CAUSES로 연결되는 threshold 통과 Event 중 Primary 순위 최고에게 우선 제공한다. 그런 Event가 없으면 일반 Primary 순위로 채운다. 마지막 자리는 남은 두 kind의 통합 Primary 순위 최고를 고른다. 같은 점수면 source start/end, kind, local ID 순이다. CAUSES logit과 ABOUT은 순위에 쓰지 않으며 threshold 미달 proposition은 다시 넣지 않는다. 이 quota는 `LEGACY_DIAGNOSTIC` 출력에는 적용하지 않는다.
- 선택된 Event마다 ACTOR/TARGET/PLACE 각각 최대 한 Entity endpoint만 공개한다. 기존 Participant source score가 가장 높은 resolved role fact를 고르고, 동점은 대표 Event member 포함 여부와 source 좌표·Entity ID 순으로 결정한다. 선택된 endpoint의 같은 role·Entity에 속하는 exact source 근거는 한 edge에 합친다. 다른 endpoint의 role fact는 내부 closure에만 유지한다. 선택된 Statement의 resolved ASSERTED_BY도 공개한다. SPAN_ONLY/미해결 Assertor·role은 내부 근거로 남고 fake Entity는 없다. `MENTIONS`는 살아남은 Entity에만 부가한다. 각 공개 Entity의 `merged_mentions`는 closure에서 source order로 골라 둔 서로 다른 비대표 exact span 최대 3개이며 `{text,start,end}`만 포함한다. singleton은 빈 배열이다. 전체 candidate 객체를 PUBLIC 단계까지 보관하지 않는다.
- Entity 대표는 대명사 여부·최종 타입 일치 다음에 명백한 표면 경계 잡음을 보고 고른다. 조사 suffix는 같은 cluster의 깨끗한 exact 표면형이 있을 때만 잡음으로 취급한다. PUBLIC `canonical_name`만 보수적으로 정리할 수 있으며 대표 `text/start/end`, evidence 좌표 및 cluster membership은 exact source 그대로 유지한다.
- 정상 serving은 Relation·Primary가 완전한 Event closure를 소비한 뒤 전체 construction의 source/endpoint 계약을 먼저 검증한다. PUBLIC 전용 carrier에서는 선택되지 않은 Event의 role/trigger/time/member grounding을 비우되 ID·anchor와 relation omission 계산은 유지한다. 선택된 Event의 모든 scalar fact는 canonical text와 역할 근거가 끝날 때까지 남긴다. 닫힌 Event member tensor lease는 member 원본 튜플도 해제한다. audit/debug 경로는 완전한 closure를 유지하며 이 축약을 적용하지 않는다.
- 선택된 Event의 실제 `LocalTimeFact`가 가리키는 Time 중 `YYYY`, `YYYY-MM`, `YYYY-MM-DD`의 유효한 단일 calendar point만 PUBLIC Time과 OCCURRED_ON으로 만든다. FY·interval·null·미연결 Time은 내부 construction에 남는다. 연도를 월/일로 보정하지 않는다.
- ABOUT/CAUSES는 선택 후 양 endpoint가 남을 때만 출력한다. 관계 때문에 proposition을 부활시키지 않는다. `CAUSES`는 방향이 있고 자기 관계는 금지한다.
- 모든 PUBLIC edge는 최상위 `confidence`(유한 [0,1])를 가진다. 값은 그 edge를 만든 판단 logit의 clamped sigmoid다. 원천: COVERS·CONTAINS_STATEMENT는 member 수용 gate `min(semantic validity, boundary fitness)`(Event cluster는 member 중 max), MENTIONS는 closure가 합친 Entity candidate decision score(NER 후보는 native type decision, ROLE-only 후보는 participant role decision) 중 max, ACTOR/TARGET/PLACE는 endpoint를 고른 winning role fact의 최고 source score, OCCURRED_ON은 Event member×Time occurrence attachment logit 중 max, ASSERTED_BY는 선택된 assertor–Entity pair logit, ABOUT/CAUSES는 accepted pair logit이다. Entity coreference·Event identity·Primary score는 confidence 원천이 아니다. 원천 head는 BCE 학습이지만 cohort별 평균 loss라 prevalence calibration이 없으므로 model probability로만 해석한다. 출력되는 edge의 원천이 없으면 기본값 없이 projection이 실패한다. score는 carrier가 아닌 `V3ConstructionResult.edge_scores` sidecar(`public_confidence.py`)로 전달하고 raw relation logit은 내부 `RelationFact`에만 남는다.
- COVERS `isPrimary`는 학습 target이 아니라 선택된 Event의 **학습 완료된** raw score 최대값에 대한 projection 정책이다. 동점은 source start/end와 final local ID로 결정한다. Event 0개, 미학습/누락 score면 `PERSISTENCE_NOT_READY`이고 대표를 만들지 않는다. 선택된 P6 checkpoint의 Primary·Primary adapter optimizer update를 검증한 project-final loader는 `TRAINED_PHASE6_CHECKPOINT_BOUND`를 전달한다. `PUBLIC.persistence_ready`는 그래프 저장 전제이며 release의 predicted-validation provenance와 독립적이다. N1 Article 저장은 COVERS ≥1·정확히 하나의 isPrimary가 있을 때만 가능하다. 추론에서 zero-event인 경우는 별도로 반환한다.
- schema `articlelocal-kg-public-v3`는 v2.2와 별개다. `validate_public`은 노드/간선 필드 allowlist, Entity taxonomy, Time 정밀도, source offset, endpoint 연결성, semantic Entity/Time 생존 조건과 저장 전제를 검사한다. JSON Schema와 viewer adapter가 같은 version을 사용한다. serializer는 finite JSON과 pretty 출력을 지원한다.
- viewer adapter는 Event/Statement label로 실제 `canonical_text`를 읽고 provenance를 node properties에 유지한다. `project_neo4j_dry_run`은 Event.title/Statement.text와 `canonicalProvenance`를 제안 속성으로 전달한다. local ID와 `backend_uuid: null`을 분리하고, 모든 UUID 및 EntityType 세분 매핑을 `unmapped`에 기록한다. `primary_score`는 PUBLIC scalar로 유지하며 backend 저장 속성은 미확정으로 보고한다. DB write, global matching, Story, MySQL ID, 계층형 Time node 생성은 없다.

`project_public(..., canonical_text_mode="GROUNDED_R2")` 외부 mode 이름은 호환성을 위해 유지한다. 진단용 `SOURCE_ONLY`는 동일 construction과 selection에서 표시문만 대표 source span으로 돌린다. 두 mode의 node ID/kind, edge, role/relation endpoint, Primary, selection, persistence 상태는 같아야 한다. source clause index는 선택된 proposition이 있을 때 요청당 한 번 생성해 공유한다.

초기 fresh-init 진단 checkpoint의 `UNTRAINED_FRESH_WEIGHT_DIAGNOSTIC` 상태는 역사적 fixture에만 해당한다. 현재 project-final 번들은 선택된 P6 checkpoint의 Phase 6 Primary 학습 provenance와 D2/E1·policy SHA를 검사해 실행한다. 번들의 inference/service readiness와 source predicted-validation provenance는 서로 다른 metadata다. 별도 predicted-validation artifact가 없어도 project-final PUBLIC 추론은 실행하며, graph-level 저장 전제를 만족하면 `PERSISTENCE_READY`를 반환한다. 전체 관계 universe가 큰 경우에도 PUBLIC-only allowed pair 집합을 bounded fine 입력으로 사용하고, unrestricted 진단은 기존 relation routing gate를 유지한다.
