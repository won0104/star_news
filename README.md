# 🌟 별빛 뉴스

> 흩어진 뉴스를 연결해, 맥락을 따라 탐색하는 지식 그래프 기반 뉴스 서비스

**별빛 뉴스**는 여러 기사를 사건과 이슈의 흐름으로 묶고, 관련 인물·기관·장소·개념을 지식 그래프로 연결합니다. 사용자는 단편적인 기사 소비에서 벗어나 뉴스의 원인과 후속 흐름을 탐색할 수 있으며, 실제로 읽은 기록을 개인 지식 그래프로 쌓아 자신의 관심 분야와 아직 접하지 못한 정보를 발견할 수 있습니다.

## 📌 프로젝트 개요

- **서비스명:** 별빛 뉴스
- **팀명:** 카운팅스타
- **핵심 가치:** 뉴스 간 관계 탐색, 읽은 지식의 축적, 정보 공백 기반 추천
- **뉴스 분야:** 정치, 경제, 사회, 생활/문화, IT/과학, 스포츠/엔터

## 💡 개발 배경

기존의 뉴스 소비 방식에는 다음과 같은 문제가 있습니다.

1. **뉴스가 하나의 지식으로 이어지지 않습니다.**  
   사건·인물·기업·주제 사이의 관계를 파악하려면 사용자가 관련 기사를 직접 검색해야 합니다.

2. **많이 읽어도 쌓인 지식이 보이지 않습니다.**  
   단순 열람 기록만으로는 내가 자주 본 분야와 아직 접하지 못한 영역을 확인하기 어렵습니다.

3. **개인화될수록 정보의 범위가 좁아질 수 있습니다.**  
   기존 추천은 비슷한 주제를 반복 노출해 관심 분야 안의 새로운 이슈를 놓치게 만들 수 있습니다.

별빛 뉴스는 기사를 개별 콘텐츠로 제공하는 데 그치지 않고, 뉴스 사이의 관계와 흐름을 연결해 사용자가 맥락을 이해하고 자신만의 지식 지도를 만들어 갈 수 있도록 합니다.

## ✨ 주요 기능

### 1. 전체 뉴스 탐색

- 주요 사건·이슈와 관련 인물·기관·개념을 연결한 공용 지식 그래프 제공
- 오늘의 주요 뉴스와 분야별 이슈를 그래프, 플로우, 목록 형태로 탐색
- 사건의 원인과 대응, 후속 사건으로 이어지는 흐름 확인
- 실제 발생한 사실과 기사 속 전망·주장·평가를 구분해 제공

### 2. 개인 지식 그래프

- 사용자가 실제로 읽은 뉴스만 개인 그래프에 반영
- 읽은 기사 속 사건·인물·기관·개념을 연결해 개인 지식 지도 확장
- 많이 읽은 분야와 상대적으로 덜 접한 영역을 시각적으로 확인

### 3. 개인화 뉴스 추천

- 자주 보는 분야의 새로운 사건과 이슈 추천
- 관심 분야 안에서 덜 접한 이슈와 개념을 **정보 공백**으로 찾아 추천
- 사용자가 명시한 비선호 분야는 추천 대상에서 제외

### 4. 검색 및 분야별 탐색

- 키워드와 문장 검색을 통해 관련 사건·이슈·인물·기관·개념 탐색
- 6개 뉴스 분야별 주요 이슈와 연결된 뉴스 흐름 제공

### 5. 읽기 기록 및 리포트

- 읽은 뉴스를 최신순, 분야별, 이슈별로 조회
- 분야, 언론사, 주간 변화, 주요 이슈 및 개념 분포 등 뉴스 소비 패턴 제공

## 🚀 서비스 차별점

| 구분 | 별빛 뉴스의 특징 |
| --- | --- |
| 뉴스 탐색 | 개별 기사가 아닌 사건과 장기적인 이슈의 흐름으로 탐색 |
| 맥락 이해 | 사건의 원인·대응·후속 관계와 관련 개념을 지식 그래프로 연결 |
| 정보 구분 | 실제 사실과 기사 속 전망·주장·평가를 구분 |
| 지식 축적 | 실제로 읽은 기록을 개인 지식 그래프로 시각화 |
| 뉴스 추천 | 비슷한 기사 반복이 아닌 관심 분야 내부의 정보 공백을 발견해 추천 |

## 👤 주요 사용자

- 오늘의 중요한 뉴스와 이슈를 빠르게 파악하고 싶은 사용자
- 하나의 사건을 배경, 원인, 후속 대응까지 깊이 탐색하고 싶은 사용자
- 읽은 뉴스를 기록하고 자신의 관심 분야와 지식 분포를 확인하고 싶은 사용자
