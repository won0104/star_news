# 구현 계약

## 중심 실행 흐름

1. 홈은 `views.home.trend_period_order`와 `trend_periods`로 기간 버튼, 급상승
   요약, seed 위치, hover 통계와 기준 시각을 함께 갱신합니다.
2. 카테고리·찾아보기는 `views.json`의 해당 seed를 화면에 배치합니다.
3. 노드를 누르면 해당 node id로 탐색 세션을 시작합니다.
4. 탐색 화면은 `navigation[nodeId].neighbor_node_ids`와 `article_ids`를 렌더링합니다.
5. 다음 노드를 누르면 선택 노드가 중심으로 이동하고 세션 경로가 갱신됩니다.
6. 탐색의 우측 기사 패널은 항상 고정하고, 노드 이동 시 내용만 교체합니다. 실제 원문 이동은 `external_link_available`과 `url`을 따릅니다.
7. 나의 기록과 리포트는 `user_events`, `user_report`, 기사·노드 데이터를 사용합니다.
8. 개인 기록 지도는 개인 기록 부분집합을 pan/zoom 가능한 SVG viewport에서 표시합니다.

## 그래프 구현

현재 데이터는 노드 83개, 엣지 425개이므로 목업에서는 네이티브 SVG로 충분합니다.

레이어 순서:

1. 점 배경
2. 일반 엣지
3. 세션 경로 및 선택 엣지
4. 노드 링과 중심점
5. 라벨
6. hover preview와 기사 패널

탐색 그래프는 전체 425개 엣지를 한 번에 표시하지 않습니다. 현재 노드의 이웃 2~8개만 펼치며, 엣지는 실제 노드 중심 좌표에 연결합니다. 개인 기록 지도만 개인 부분집합 전체를 표시하고 wheel/pinch zoom, drag pan, 선택 필터를 지원합니다.

가중치 시각화는 모든 화면에서 같은 순서를 따릅니다.

1. 현재 화면에 표시되는 원시 값을 제곱근 곡선으로 0~1 정규화합니다.
2. 홈·분야·검색 seed와 탐색 이웃은 `11–24px`, 기록 요약은 `10–24px`, 개인 지도는 `7–28px`로 변환합니다.
3. 홈·추천·분야·검색 seed의 위치는 가중치 순서와 무관한 결정적 랜덤 좌표를 사용합니다. 같은 화면·기간·검색어에서는 위치가 유지되고, 가중치는 크기에만 반영합니다.
4. 홈 기간은 `article_count`, 검색은 관련도, 분야는 `trend_score`, 기록·개인 지도는 `read_count`를 노드 가중치로 사용합니다.
5. 탐색 엣지는 `weight`가 클수록 중심과의 목표 선 길이를 `320px → 140px`로 줄이고 두께·불투명도는 보조적으로만 높입니다. 이웃은 정수평·정수직과 정반대 배치를 피한 비대칭 각도 슬롯 안에서 현재 탐색 상태를 기준으로 결정적으로 섞어, 가중치순 정렬처럼 보이지 않으면서 같은 상태에서는 배치를 유지합니다. 별·글로우·라벨이 그래프 밖으로 잘리지 않도록 목표 거리가 안전영역을 넘는 경우에만 같은 방향에서 실제 거리를 제한합니다.
6. 기록·개인 지도 엣지는 `read_support`로 두께와 불투명도를 정합니다. 개인 지도는 2 이상 관계를 모두 유지하고, 고립 노드만 같은 분야 구조선 또는 짧은 1 관계로 보완합니다.
7. 엣지 레이어를 먼저, 글로우·노드·링·라벨을 나중에 그려 엣지가 별 위를 덮지 않게 합니다.

## Figma에서 그대로 사용하는 것

- 1440×900 공통 shell, 224px 사이드바, 72px 헤더
- 색상, 타이포그래피, 간격, 패널과 오버레이 크기
- 내려받은 아이콘·선택 궤도·광원 에셋
- 화면별 시각 상태와 모션 pre/post 기준

## Figma에서 데이터로 가져오지 않는 것

- 화면에 적힌 예시 키워드와 기사
- 정적으로 그린 엣지와 노드 위치
- 리포트의 예시 점과 막대
- 개인 지도에 배치된 예시 라벨

이 값들은 모두 `data/mock`에서 계산하거나 조회합니다.

## 주요 상호작용 체크리스트

- 홈: 주요 트렌드/나를 위한 추천 전환, 오늘·1주·1개월·3개월 기간 변경,
  급상승 3개와 seed hover 통계 동기화, 탐색 시작
- 카테고리: 8개 분야 탭과 사이드바 진입, 분야별 seed 전환
- 찾아보기: 입력, 노드·기사 통합 검색, 결과 bloom, 노드 탐색 시작
- 탐색: 중앙 이동, 가중치별 이웃 거리·랜덤 각도 재배치, 직전 잔상 1개와 breadcrumb 경로 복귀, 고정 기사 패널 내용 교체
- 나의 기록: 최신순 기록 스크롤, 군집·주제 필터, 우측 패널 필터 해제, 전체 지도 오버레이
- 나의 리포트: 개요, 분야 분포, 주간 열람, 최근 주제 지형
- 개인 지도: pan, zoom, 노드/군집 선택, 기록 기사 패널, 나의 기록으로 복귀
- 프로필/설정: 바로가기 메뉴, 저장형 설정, 관심 없음 추가·삭제, 로그아웃 모형
- 접근성: 키보드 포커스, ESC 닫기, focus-visible, reduced motion

## 구현 기술

런타임 의존성 없이 순수 HTML/CSS/JavaScript ES Modules와 네이티브 SVG로 구현합니다.
