# 책갈피 에셋

최종 책 시안의 책갈피를 실제 배치 가능한 독립 에셋으로 다시 제작한 파일입니다.

## 폴더

- `png/1x`, `png/2x`, `png/4x`: 투명 배경 PNG. Figma에서는 보통 `2x`를 불러와 50%로 축소하면 선명합니다.
- `svg`: 크기와 색을 자유롭게 바꿀 수 있는 벡터 버전입니다.
- `preview.png`: 전체 구성 확인용입니다.

## 파일

- `bookmark-report`: 왼쪽 ‘나의 리포트’ 링크
- `tab-politics-*`: 정치
- `tab-economy-*`: 경제
- `tab-society-*`: 사회
- `tab-culture-*`: 문화
- `tab-international-*`: 국제
- `tab-sports-*`: 스포츠
- `tab-it-science-*`: IT·과학
- `tab-default-blank`, `tab-selected-blank`: 글자 없는 기본/선택 템플릿

각 카테고리에는 `-default`와 `-selected` 두 상태가 모두 들어 있습니다.

## 배치 팁

- 좌측 리포트 탭은 오른쪽의 일자 면을 책 가장자리에 맞춥니다.
- 우측 카테고리 탭은 왼쪽의 일자 면을 책 가장자리에 맞춥니다.
- PNG에는 시안과 같은 약한 그림자가 포함되어 있습니다.
- SVG의 글자는 `Pretendard → Noto Sans KR → Apple SD Gothic Neo → Malgun Gothic` 순으로 대체됩니다. Figma에서 Pretendard를 사용하면 가장 자연스럽습니다.
